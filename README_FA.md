## ⚡ فلسفه و چشم‌انداز طراحی

بسیاری از اکوسیستم‌های چند دستگاهی موجود (نظیر اکوسیستم اپل یا پلتفرم‌های اختصاصی دیگر) یا در دیوارهای بسته و انحصاری تجاری محصور هستند، یا فاقد ارتباط سخت‌افزاری سفارشی و بدون تاخیر با لینوکس و میکروکنترلرها می‌باشند. **KMBTA** بر پایه چهار اصل اساسی مهندسی شده است:

۱. **استقلال کامل از سخت‌افزار تجاری:** ایجاد پروتکل واحد و باز برای پیوند زدن میکروکنترلرهای ارزان‌قیمت (ESP32) به لینوکس (Wayland/Hyprland)، ویندوز و موبایل.  
۲. **پاسخ‌دهی زیر یک میلی‌ثانیه:** استفاده از کانال‌های محلی UDP با تاخیر ناچیز (کمتر از ۰.۱ میلی‌ثانیه) برای حرکات فیزیکی، همگام با معماری Server-Sent Events در سرور.  
۳. **طراحی سایبر-رترو صنعتی:** الهام گرفته شده از پنل‌های اویونیک هواپیماها، ترمینال‌های سایبرپانک و داشبوردهای پایش اطلاعات صنعتی با تم نئونی و کنتراست بالا.  
۴. **حریم خصوصی و خودمیزبانی ۱۰۰٪:** بدون نیاز به هیچ‌گونه سرور یا کلود شخص ثالث خارجی، همراه با فرآیند جفت‌سازی رمزنگاری‌شده با پین‌کد ۶ رقمی.

## 🛸 معماری کلی سیستم

```mermaid
graph TB
    subgraph سرور مرکزی [هاب مرکزی و پایگاه داده]
        HUB[سرور FastAPI مرکزی<br/>پایگاه داده SQLite WAL]
        WEB[استودیو وب سایبردک v5<br/>رابط کاربری رترو-فیوچر]
        SSE[باس رویدادهای زنده<br/>استریم داده‌های SSE]
        HUB --- WEB
        HUB --- SSE
    end

    subgraph نود لینوکس [لپ‌تاپ / دسکتاپ Omarchy]
        L_AGENT[ایجنت پس‌زمینه لینوکس]
        L_UINPUT[درایور مستقیم کرنل uinput]
        L_MEDIA[کنترلر صوتی PipeWire / MPRIS]
        L_AGENT --- L_UINPUT
        L_AGENT --- L_MEDIA
    end

    subgraph نود ویندوز [کامپیوتر گیمینگ / اداری]
        W_AGENT[ایجنت پس‌زمینه ویندوز]
        W_BRIDGE[بریج صدای Win32 API]
        W_PLAYER[بریج پلیر Cliamp / وستاپ]
        W_AGENT --- W_BRIDGE
        W_AGENT --- W_PLAYER
    end

    subgraph نود سخت‌افزاری [سایبردک دستی ESP32]
        ESP_CORE[میکروکنترلر ESP32 Super Mini]

        ESP_CORE --- MPU
        ESP_CORE --- TFT
    end

    subgraph نود موبایل [گوشی اندروید]
        AND_APP[داشبورد لمسی موبایل]
        AND_STREAM[پلیر استریم موزیک در پس‌زمینه]
        AND_APP --- AND_STREAM
    end

    %% خطوط ارتباطی
    L_AGENT <-->|REST + استریم SSE| HUB
    W_AGENT <-->|REST + استریم SSE| HUB
    AND_APP <-->|REST + استریم SSE| HUB
    ESP_CORE <-->|جفت‌سازی اولیه و OTA| HUB
    ESP_CORE -.->|پکت‌های فوق سریع UDP 4210| L_AGENT
    ESP_CORE -.->|پکت‌های فوق سریع UDP 4210| W_AGENT
```

## 📦 نودها و اجزای تشکیل‌دهنده

### ۱. 🛰️ سرور مرکزی و استودیو سایبردک
- **نقش:** هماهنگ‌کننده تلمتری کل اکوسیستم، صف دستورات ریموت و استریمینگ قطعات موسیقی.
- **تکنولوژی‌ها:** پایتون ۳.۱۱ به بالا، فریم‌ورک FastAPI، پایگاه داده SQLite در حالت WAL و داکر کامپوز.
- **ویژگی‌ها:**
  - بیش از ۴۰ مسیر ارتباطی RESTful برای مدیریت چرخه حیات نودها و دستورات متقابل.
  - استریم رویدادهای زنده (SSE) برای بازتاب آنی تغییرات وضعیت در کمتر از چند میلی‌ثانیه.
  - اینترفیس وب دارک با تم سایبرپانک و کلیدهای میانبر بهینه‌شده برای کیبورد و لمس.

### ۲. 🐧 ایجنت لینوکس (لپ‌تاپ)
- **نقش:** سرویس پس‌زمینه لینوکسی سازگار با محیط‌های Wayland و Hyprland.
- **قابلیت‌ها:**
  - شبیه‌سازی موس و کیبورد در سطح کرنل از طریق `/dev/uinput` بدون وابستگی به سرورهای گرافیکی.
  - پایشگر مصرف باتری، نرخ شارژ، پنجره‌های فعال و فرکانس پردازنده.
  - کنترلر یکپارچه صدا و مولتی‌مدیا از طریق سرویس‌های MPRIS و PipeWire.

### ۳. 🪟 ایجنت ویندوز (رایانه شخصی)
- **نقش:** خودکارسازی امور و اتصال ویندوز به هاب مرکزی.
- **قابلیت‌ها:**
  - کنترل سطح صدا و میوت کردن از طریق توابع سیستمی Win32 Core Audio.
  - پل صوتی اختصاصی با پلیرهای قدیمی و مدرن (مانند Winamp و ابزارهای خط فرمان Cliamp).
  - اجرای کامپکت و مخفی در پس‌زمینه با سرویس‌های VBS و رجیستری ویندوز.

### ۴. 📱 همراه هوشمند اندروید
- **نقش:** ریموت کنترل قابل حمل و دستگاه پخش موزیک هماهنگ.
- **قابلیت‌ها:**
  - رابط وب بهینه‌شده برای استفاده با یک دست در حالت پرتره.
  - پخش بدون وقفه موزیک‌های سرور به همراه نوتیفیکیشن کنترل صوت در صفحه قفل گوشی.

## 🎮 سایبردک سخت‌افزاری و ایرماوس

بخش سخت‌افزاری پروژه، یک سایبردک فیزیکی جمع‌وجور است که بر روی چیپست **ESP32** و سنسور ۶ محوره **MPU-6050** ساخته شده است:

```
            [ میکروکنترلر اصلی ESP32 Super Mini ]
             │                              │
             ├── (ارتباط دو سیمه I2C) ─────► سنسور ژیروسکوپ و شتاب‌سنج MPU-6050
             │
             ├── (ارتباط سریع SPI) ────────► نمایشگر رنگی 240x240 ST7789 TFT
             │
             ├── (کنترل لمسی SPI/GPIO) ────► تراشه تاچ مقاومتی XPT2046
             │
             └── (شبکه بیسیم WiFi) ────────► پکت‌های UDP 4210 حرکت نشانگر موس (<0.1ms)
                                           └── سرور وب برای آپدیت بی‌سیم (Web OTA)
```

### 🎯 حالت اشاره‌گر لیزری واقعی (Laser Pointer Mode)
برخلاف ایرماوس‌های معمولی که حرکت افقی موس را به پیچش آزاردهنده مچ دست (Roll) متصل می‌کنند، KMBTA از یک موتور حرکتی هوشمند استفاده می‌کند:
- **چرخش افقی سر دستگاه به چپ و راست (محور Yaw Z):** کنترل طبیعی حرکت افقی نشانگر موس (`dx`) دقیقاً شبیه به یک پوینتر لیزری واقعی.
- **متمایل کردن سر دستگاه به بالا و پایین (محور Pitch X):** کنترل حرکت عمودی نشانگر موس (`dy`).
- **پیچش مچ دست (محور Roll Y):** به طور کامل از حرکت موس ایزوله شده و به **ماکروهای حرکتی مچ دست (Flick Gestures)** اختصاص یافته است!

### ✋ ماکروهای حرکتی مچ دست
- **تکان سریع مچ دست به سمت راست:** پرش به آهنگ بعدی (`CMD:MEDIA_NEXT`)
- **تکان سریع مچ دست به سمت چپ:** پرش به آهنگ قبلی (`CMD:MEDIA_PREV`)
- **تکان سریع سر دستگاه به بالا:** افزایش صدای سیستم (`CMD:VOL_UP`)
- **تکان سریع سر دستگاه به پایین:** کاهش صدای سیستم (`CMD:VOL_DOWN`)

## 📡 پروتکل‌های کلیدی و قابلیت‌ها

### ۱. جابجایی هوشمند مدیا (Universal Media Handoff)
امکان انتقال پخش آهنگ میان کامپیوترها و موبایل **تنها با ۱ کلیک** با حفظ دقیق ثانیه پخش:
```json
{
  "source_device": "kmbta-laptop-01",
  "target_device": "kmbta-windows-pc",
  "track_id": "ambient-session-04",
  "position_sec": 78.4,
  "action": "play"
}
```

### ۲. همگام‌سازی کلیپ‌بورد سراسری (Universal Clipboard)
انتقال لحظه‌ای متن‌های کپی شده بین لینوکس، ویندوز و گوشی اندروید بدون نیاز به ابزارهای جانبی.

### ۳. پکت‌های شبکه ایرماوس (پورت UDP `4210`)
```text
CMD:MOUSE:<dx>,<dy>     # جابجایی نسبی مختصات نشانگر موس
CMD:CLICK:LEFT          # کلیک چپ
CMD:SCROLL:<delta>      # اسکرول عمودی چرخ موس
CMD:MEDIA_PLAY_PAUSE    # کلیدهای کنترل مولتی‌مدیا
```

## 🔒 مدل امنیت و حفظ حریم خصوصی

- **عدم ذخیره هیچ‌گونه رمز عبور:** تمامی کدهای عمومی فاقد توکن‌های اصلی، آدرس‌های آی‌پی شخصی یا اطلاعات اتصال به وای‌فای خانگی هستند.
- **احراز هویت دومرحله‌ای دستگاه‌ها:** هر نود جدید قبل از دریافت کلید اختصاصی `X-Device-Token`، نیازمند تایید پین‌کد ۶ رقمی است.
- **جداسازی دسترسی مدیر:** امور حساس نیازمند ارسال توکن ۶۴ رقمی ادمین (`X-KMBTA-Admin`) هستند.
- **پایداری شبکه محلی:** در صورت قطع ارتباط با اینترنت، نودها در شبکه داخلی از طریق UDP Broadcast به کار خود ادامه می‌دهند.

## 🚀 راهنمای راه‌اندازی سریع

### اجرای هاب مرکزی در داکر
```bash
# ۱. دریافت ریپازیتوری
git clone https://github.com/denkikmbta/kmbta-ecosystem.git
cd kmbta-ecosystem

# ۲. ایجاد فایل تنظیمات محیطی
cp .env.example .env
# متغیر KMBTA_ADMIN_TOKEN را مقداردهی فرمایید

# ۳. راه‌اندازی با داکر کامپوز
docker compose up -d
```

### اجرای دریافت‌کننده ایرماوس در لینوکس
```bash
chmod +x bin/kmbta-airmouse
./bin/kmbta-airmouse --daemon
```
